The mark

A single continuous stroke on a 32×32 grid. The stroke tapers along its path, so the C reads as a signal with direction rather than a geometric ring. The node in the aperture is where the trace continues — the same object that runs down the site as a scroll trace and spins as the app's only spinner.

Variant A — 60° aperture
gap 60° · taper 2.4→3.6 · node on-path r1.5
Archived

The brief's baseline. At 20px the 60° gap measures 11px of arc and the node sits close enough to both terminals that the counter starts to close — it reads as a broken ring, not an aperture.
